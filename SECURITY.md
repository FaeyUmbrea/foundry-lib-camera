# Security policy

## Supported versions

Security fixes target the latest release for each supported Foundry generation.
The initial supported generations are Foundry 13 (13.351 or later) and 14.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/FaeyUmbrea/foundry-lib-camera/security/advisories/new).
Include the affected versions, reproduction steps and expected impact.

Please keep vulnerability details out of public issues until a fix is available.

# libCamera

Camera ownership, priorities and viewport control for Foundry VTT.

Coordinates camera control between cooperating modules, with user priorities,
movement and framing, viewport following, and optional 3D Canvas support.
The native control panel lets users release control or stop camera movement.

Releases are available for [Foundry 13.351 and later](https://github.com/FaeyUmbrea/foundry-lib-camera/releases/tag/v1.13.3)
and [Foundry 14](https://github.com/FaeyUmbrea/foundry-lib-camera/releases/tag/v1.14.3).

- [Technical documentation and development](https://tasks.void.monster/articles/LIBCAMERA-A-1)
- [User documentation](https://docs.void.monster/lib-camera/)
